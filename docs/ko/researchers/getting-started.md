# 연구자 시작하기

일하는 방식에 맞는 길을 고르세요. 보정된 시범 데이터를 연구자가 웹에서 바로 받는 기능은 **오늘 제공되지 않습니다.** 이 페이지에서 보정 CSV를 한 번에 받을 수 있다고 기대하지 마세요.

## 길 A — 읽고 살펴보기 (설치 없음)

1. [할 수 있는 일](../what-you-can-do/)과
   [당뇨병–입원 예시](../diabetes-hospitalization-example/)를 읽습니다.
2. [데이터 이해하기](../understanding-the-data/)에서 사람 단위와 청구 단위의 차이를 훑습니다.
3. 제안서나 발표에 숫자를 쓰기 전에 [결과 해석](../interpreting-results/)과
   [한계와 범위](../limitations/)를 읽습니다.

Python을 쓰지 않아도 이 도구가 자신의 연구와 맞는지 판단할 수 있습니다.

## 길 B — 분석가 인수인계 (R, Stata, Python 등의 표)

1. 패키지를 실행할 수 있는 동료에게 **올바른 시나리오 예시**(구조 연습용 데이터)를
   [내보내기와 릴리스 (영어)](../../../developers/export-and-release/) 절차로 내보내 달라고 부탁합니다.
2. 나온 CSV 또는 Parquet를 자신의 분석 환경으로 불러옵니다.
3. 파일은 코드 연습용 인공 구조로 다룹니다. 동료가 별도의 5단계 합성 세계 절차를 실행하고 그 산출물이라고 분명히 표시하지 않았다면, 보정된 연구 시범이 아닙니다.

따로 포장된 표본 데이터가 나중에 승인되면, 이 페이지에 확인된 파일 위치, 허용 용도, 체크섬을 적습니다. 그 경로는 **오늘 있는 기능으로 문서화되어 있지 않습니다.**

## 길 C — 개발자 설정

로컬에 설치하고 CLI/API를 사용합니다. 아래 문서는 영어입니다.

- [설치](../../../developers/installation/)
- [첫 실행](../../../developers/first-run/)
- [보정된 월드](../../../developers/calibrated-worlds/)

## 책임 있는 사용

고른 공개 통계에 맞춰 조정해도, 합성 코호트로 실제 메디케어의 유병률, 효과, 정책 주장을 뒷받침할 수는 없습니다. 자주 마주치는 경계는 [자주 묻는 질문](../faq/)을 보세요.
