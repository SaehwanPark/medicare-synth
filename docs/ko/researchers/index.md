# 연구자 안내

Medicare-Synth는 제한된 메디케어 자료를 다루기 전에, 메디케어와 비슷한 인공 데이터로 아이디어를 살펴보게 해 줍니다. 연구 준비와 방법론 시험용 작업 공간이며, 메디케어 모집단 추정치의 출처는 아닙니다.

이 한국어 페이지는 연구자용 영문 문서와 같은 내용을 옮긴 것입니다. 영문 페이지가 기준본입니다. 개발자 문서와 기술 기준 문서는 영어로만 제공합니다.

## 목표를 고르세요

### 있는 데이터 살펴보기

수급자, 자격, 질환, 청구 형태 기록이 어떻게 이어지는지, 한 행이 사람 수와 어떻게 다른지 확인합니다.

→ [데이터 이해하기](understanding-the-data/) ·
[할 수 있는 일](what-you-can-do/)

### 분석 설계하기

지원되는 2021년 전통적 메디케어 FFS형 당뇨병·입원(원인 무관) 예시를 따라가 봅니다. 어떤 항목이 있는지, 어떤 공개 통계를 기준으로 삼았는지, 제한 자료에 접근하기 전에 코드로 무엇을 연습할 수 있는지 알 수 있습니다.

→ [당뇨병–입원 예시](diabetes-hospitalization-example/) ·
[시작하기](getting-started/)

### 가정 비교하기

고른 공개 비율은 같아도, 자유롭게 둔 가정(예를 들어 배경 입원 위험)이 다르면 합성 데이터가 달라질 수 있습니다. 분석 코드를 압박해 보는 데 쓰고, “그” 메디케어 답을 되찾는 데 쓰지 않습니다.

→ [결과 해석](interpreting-results/) ·
[한계와 범위](limitations/)
