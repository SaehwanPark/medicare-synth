# 결과 해석

합성 산출물은 분석 결과처럼 보일 수 있습니다. “타당함”을 네 층으로 나눠 두세요.

| 층 | 질문 | 지금 이 과제가 서는 곳 |
| --- | --- | --- |
| 1. 구조 | 표가 연결되고 형식·관계 검사를 통과하는가? | 예시와 시범 관문에서는 강함 |
| 2. 고른 요약 수치 | 고른 요약 비율이 공개된 기준 근처에 있는가? | 범위가 정해진 5단계 보정 (등급이 매겨짐. 일반화의 증명은 아님) |
| 3. 작업 절차의 현실성 | 밝힌 분석 절차에 쓸 만큼 데이터가 현실적인가? | 6단계 독립 평가가 필요함 (진행 중) |
| 4. 모집단 추론 | 결과를 메디케어의 참으로 볼 수 있는가? | **이 과제의 주장이 아님** |

## 말해도 되는 것 / 말하면 안 되는 것

| 말해도 되는 것 | 말하면 안 되는 것 |
| --- | --- |
| “이 예시가 외래키 검사에 실패했으니, 조인 코드는 그 오류를 다뤄야 한다.” | “메디케어의 고아 청구 비율이 이것이다.” |
| “이 합성 가정에서 내 코호트 정의는 N명을 돌려줬다.” | “따라서 N이 메디케어 코호트 크기다.” |
| “두 합성 세계는 같은 보정 목표에 맞았지만 자유로운 배경 위험이 달랐고, 내 추정치가 움직였다.” | “메디케어의 참 효과는 그 두 추정치 사이에 있다.” |
| “보정이 고른 학습 요약 수치의 오차를 줄였다.” | “모형이 임상적으로 검증되었거나 모집단을 대표한다.” |
| “자료이용계약과 제한 추출본 전에 코드를 고치려고 합성 데이터를 썼다.” | “합성 데이터에서의 성능이 임상·정책 결론을 정당화한다.” |

## 시뮬레이션 참값과 메디케어 실증 참값

참값을 아는 실험에서는 생성기의 매개변수를 분석자가 통제합니다. 그 매개변수를 되찾는 일은 분석 코드가 이어졌는지 확인하는 일입니다. 같은 숫자가 메디케어에 있다는 뜻은 **아닙니다**.

시범의 공개 보정 기준은 출처 연도와 근거의 세기를 일부러 섞어 둡니다. 연도와 집단을 옮긴다는 가정을 밝힌 맥락상의 목표로 다루세요.

## 해석에 영향을 주는 시범의 빈칸

- 시범에서 당뇨병과 심부전은 서로 독립으로 뽑습니다 (동반질환 의존을 튼튼히 두지 않음).
- 여러 해에 걸친 질환 궤적이나 제공자 효과를 튼튼히 두지 않습니다.
- 입원은 모든 원인의 입원 여부이며, 진단이 특정된 입원이 아닙니다.
- 하위집단 성능이나 교란 구조가 현실적이라고 말하지 않습니다.
