# 당뇨병–입원 예시

## 질문

제한된 메디케어 파일을 분석하기 전에, 당뇨병이 있는 사람과 없는 사람의 입원 발생을 비교하는 코드를 어떻게 시험할 수 있을까요? 합성 답이 메디케어의 답이라고 말하지 않으면서요.

## 코호트 (인공)

- **상황:** 2021년 전통적 메디케어 행위별 수가(FFS)와 비슷한 집단
- **나이:** 65세 이상
- **자격:** 이 과제의 단순화된 자격 규칙으로 한 해 내내 파트 A/B
- **맥락 ID:** `mvp-2021-om-ffs-diabetes-ip`

방법론 개발을 위한 합성 기록입니다. 복원된 수급자가 아닙니다.

## 핵심 표와 항목

이 시범에서 분석가가 보통 마주치는 조각입니다.

| 조각 | 예시에서의 역할 |
| --- | --- |
| 수급자 인구학 | 인공 코호트에 누가 있는지 |
| 자격 | 단순화한 연중 A/B 가입 |
| 만성질환 표지 | 당뇨병(`sp_diabetes`)과 심부전(`sp_chf`) 플래그 |
| 입원 청구 | 입원 청구가 적어도 한 건 있는지 (모든 원인) |

중요한 정의: 결과는 **어떤 입원이든** 입니다. 당뇨병이 주진단인 입원도, 당뇨병 때문이라고 특정된 입원도 아닙니다. 심부전은 층화·표지로 쓸 수 있으며, 동반질환 체계를 모두 모형화한 것은 아닙니다.

## 공개 기준 (고른 값, 대략)

5단계 합성 세계는 얼려 둔 보정 목표 세 가지를 공유합니다.

| 목표 | 대략적인 값 | 출처의 위치 |
| --- | --- | --- |
| 당뇨병 유병률 | 27.7% | 2018년 CMS 집계 (2021년 맥락으로 옮김) |
| 심부전 유병률 | 12% | 2022년 CMS 집계 (옮김) |
| 당뇨병이 있는 사람의 입원 위험 | 약 13% | 더 약한 업계 사전 정보 (동료평가를 거친 메디케어 추정치 그 자체는 아님) |

연도와 집단을 건너 옮기는 일은 명시적인 근사입니다. 이 수치에 맞는다고 2021년 메디케어를 종합적으로 벤치마크한 것은 아닙니다.

## 저장된 5단계 합성 세계의 그림

아래 예시는 모두 가상 수급자 **6,000**명이고, 고른 보정 목표는 같습니다. 자유롭게 둔 가정은 다릅니다.

| 합성 세계 (저장된 예) | 방법의 특징 | 자유로운 배경 입원 가정 | 입원 청구 기록 (저장값) |
| --- | --- | --- | --- |
| 기준 생성기 | 생성기 매개변수를 목표 쪽으로 조정 | P(입원 \| 당뇨병 없음) = 0.04 | **404** |
| 다른 배경 위험 | 같은 보정 목표 | P(입원 \| 당뇨병 없음) = 0.08 | **572** |

이 건수는 저장소에 들어 있는 5단계 묶음 요약
(`reports/phase5/world_family_summary.json`)에서 옵니다. 모든 실행 설정의 보편적인 기대 건수가 아니라, 저장된 그림입니다.

## 연습할 수 있는 일

- 수급자 표와 청구 형태 표를 묶고 합치기
- 노출(당뇨병 표지)과 결과(입원 청구가 한 번이라도 있는지) 정의하기
- 분석 단위 확인하기 (사람 대 청구)
- 단순한 연관성을 **코드 시험**으로 돌려 보기
- 보정 목표는 같고 자유 가정만 바뀔 때의 민감도 확인

## 추론할 수 없는 일

- 실제 메디케어에서 당뇨병이 입원에 미치는 효과
- 검증된 예측 성능이나 위험 보정 성능
- 진단이 특정된 입원 패턴
- 인과 효과, 정책 결론, 모집단을 대표하는 비율
- 6단계 독립 평가가 끝났다는 결론 (아직 진행 중)

## 재현 (개발자 경로)

웹사이트에 코딩 없이 받는 보정 다운로드는 없습니다. 5단계 요약을 프로그램으로 재현하려면:

```shell
uv run python scripts/phase5_emit_worlds.py
```

문헌과 짝을 맞춘 따라 가기(영역 안: Andes MMWR 유병률, 영역 밖: Drye 입원률)는 저장소의 예시를 보세요.

```shell
uv run python examples/andes-mmwr-drye-diabetes/scripts/run_example.py
```
